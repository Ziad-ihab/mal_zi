لو الإضافة بتاخد وقت طويل جداً أو مش بتتحفظ خالص، السبب غالباً واحد من دول:

===================================================
السبب المشهور: قواعد الأمان (Firestore Rules) لسه مقفولة
===================================================
من Firebase Console:
Build > Firestore Database > Rules

امسحي اللي موجود وحطي ده بدله:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /malak_content/{doc} {
      allow read, write: if true;
    }
  }
}

بعدين دوسي "Publish". وجربي تضيفي حاجة تاني.

===================================================
ملحوظة عن الصور
===================================================
مبقيناش بنستخدم خدمة Firebase Storage خالص (لأنها بقت محتاجة خطة
مدفوعة "Blaze" حتى للاستخدام المجاني البسيط). دلوقتي الصورة بتتضغط
وتتحفظ كنص جوه Firestore نفسها مباشرة — يعني مش هتحتاجي تفعّلي
Storage أصلاً، وده هيخلي الإضافة أسرع وأبسط.

لو ظهرلك خطأ بيقول إن الصورة "كبيرة على قاعدة البيانات"، معناه
الصورة اللي اخترتيها لسه كبيرة جداً — جربي صورة تانية بدقة أقل،
أو التقطيها بجودة أقل من الكاميرا.

===================================================
ملحوظة عن الأمان
===================================================
الـ Rule دي بتخلي أي حد عنده لينك الموقع يقدر يضيف محتوى — مناسبة
لموقع شخصي بسيط. لو حبيتي تحمي الإضافة بباسورد بسيط بعدين، قولي
وهظبطها.
